Favoritos

Cadastre tickers para comparar oportunidades de investimento com dados de mercado e um score de 0 a 100.

Dois rankings: o painel lateral é seu ranking pessoal. Arraste os ativos para cima ou para baixo para definir a ordem que você prefere. Na área principal fica o ranking técnico, calculado pelo score e pelos demais critérios. Use o botão + da lateral para colocar um favorito na lista principal e disparar a consulta à API.
Meu ranking pessoal
Arraste para ordenar. A lista lateral guarda todos os favoritos.
Lista principal · análise técnica
Somente os favoritos marcados com ✓ na lateral aparecem aqui.
Score de 0 a 100 para triagem da carteira. Não é recomendação de compra ou venda. Liquidez, tamanho, volatilidade e risco são calculados a partir dos dados disponíveis; qualidade, gestão, P/VP, DY e histórico de dividendos só entram no score quando houver dados confiáveis na fonte.

Layout para celular

Automático ativa em telas de até 720 px. “Ligado” força o layout de celular em qualquer tela. Vale só para este aparelho.

Fica salvo apenas neste navegador — não vai para o código publicado nem para o backup.

O backup inclui investimentos e lançamentos, tickets e dados de mercado salvos, Favoritos e ranking pessoal, estratégia de FII, metas, ordem da carteira e as notas (estrelas) de cada investimento. A chave da API não é exportada.
